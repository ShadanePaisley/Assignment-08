# Module 8 Assignment

This repository contains my work for Module 8 Assignment: Data Lookup with Dictionaries & Basic Aggregation.

## Files Included
- module08-assignment.py

## What I Practiced

In this assignment, I practiced creating and managing nested dictionaries to organize customer information, projects, and service data, while using dictionary methods like `.get()`, `.keys()`, `.values()`, and `.items()` to retrieve and process information efficiently. I performed data aggregations using built-in functions such as `sum()`, `min()`, `max()`, and `len()` to calculate totals, averages, and identify extremes across multiple datasets. I also built dictionary comprehensions to filter and transform data, developed validation and analysis functions that work with complex dictionary structures, and combined loops, conditionals, and dictionaries to create a complete customer management system with business reporting capabilities.
